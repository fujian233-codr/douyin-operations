# 抖音运营知识库 · 算法与数据

## 一、平台算法

### 审核机制

- 发布后先机审：敏感词（广告法/法律/平台禁词/黑五类）→ 营销广告判定 → 去重检测（特征与数据库历史内容比对，高度重合判抄袭→打回或限流）
- 疑似违规进人审；确认违规删视频，严重封号
- 图文平台调性是种草分享：上来发产品/服务/价格=营销广告，前期损害极大
- 可以组合他人内容的优秀价值点，但必须用自己的话重写（或 AI 改写），不能原样搬

### 流量池模型

- 系统为账号划定流量上下限；新视频给 200–300 播放测试
- 每个池之间有"阀门"=指标阈值（完播、点赞率、评论等）；达标进下一池（约3000），再达标继续放大；不达标流量终止
- 高权重账号初始可给 ~1000 播放
- 播放量极低（十几二十）常见原因：画面/文案与已有内容重复度高 → 被限流到仅粉丝可见
- 被投诉的内容直接进人工审核，跳过机审

### 标签系统

- 创作者标签：平台通过分发人群的行为反馈（而非你的标题/标签文案）判断内容赛道
- 账号标签形成过程（多轮测试模型）：500流量中有10个精准用户→5个提供行为数据→平台无法确认→第二波提升精准用户占比继续测→数据持续达标→逐波放大；若各赛道人群测试全部失败，账号基本作废
- 流量基数放大后用户更挑剔，数据率自然衰减（200人可能50%互动，1000人只30%）
- 用户标签：搜索行为、停留时长、点赞收藏实时改变推送方向；用户标签反向决定账号会被推荐给谁

### 平台属性

- 抖音=高度去中心化分发，规则透明，对新手创作者友好；快手=中心化，偏向头部达人
- 抖音流量最大但泛粉多：做特别垂直精准的内容反而难，破圈爆款要抓泛粉（想看"想成为的样子"的人群，高级又接地气，反差感最易爆）
- 养号说法多数无目的无依据（类比：天天去别人服装店逛，自家店生意不会变好）

## 二、数据指标与复盘

### 指标含义与优先级

- 完播考核两秒跳出率 + 5秒完播率
- 指标重要性：关注 > 点赞评论 > 完播；但提升顺序应反过来：完播（开头5秒最好改）→ 点赞评论 → 关注（最难，靠内容和人设长期积累）
- 用户行为动机：点赞=内容有价值/有趣；评论=画面细节有讨论点；转发=想分享给朋友或讨论；关注=对账号长期有期待

### 短视频结构公式

- 开头：吸引人的画面/提问/标题/高潮前置（探店把"最难吃的菜"放开头）
- 中间：结构化输出——提出问题→解决问题
- 结尾：抛观点/提问引导评论，引导关注

### 数据复盘方法

- 入口：抖音App → 创作者中心 → 数据详情/作品分析；电脑端创作者中心同步可用
- 基准：5秒完播 ≥50% 达标、≥70% 优秀；两秒跳出越低越好；平均播放时长越长越好
- 互动看比率（点赞率/评论率/分享率）不看绝对量
- 类型必须统一才可比：美食跟美食比，带货跟非带货不可比
- 对标方法：确定自己所在流量池 → 找同类型、粉丝量高一级（如1万粉对1–10万粉）的达人 → 用达多多（有免费查询）、蝉妈妈等数据网站看其播放/互动并计算比率 → 对照自己找差距 → 也对照观众画像

### 数据的基数前提

- 几百播放量的数据无分析价值（新号初期流量≈边缘流量/垃圾流量）
- 数据好可能运气好，数据差可能运气差；基数放大后才可信（这也是投抖加的意义之一）

## 三、抖加投流

- 本质：加热工具，只放大已有概率，不救差内容
- 30元测审法：疑似隐形限流时投30元，能过审=内容没问题；过不了=视频有问题，直接重发，不必纠结
- 成型团队建议每条视频发布后小额投测，用真实基数检验内容概率

## 四、选题方法

四维度出题公式（以汽车号为例）：

- 时间维度：`2024年最值得买的车`
- 领域/区域维度：`跑工程适合开什么车`、`城市通勤适合开什么车`
- 人群维度：`都市白领/刚毕业大学生/跑滴滴的适合开什么车`、`马云的座驾是什么`（名人+座驾天然高热度）
- 解答维度：`比亚迪为什么今年大卖`（好奇心驱动）

流程：选题定框架 → 填内容 → 结尾引导互动 → 拍摄。另外：建对标账号的爆款选题库，跟着已被验证的选题做。

## 五、拍摄剪辑要点

- 景别：远/全/中/近/特；短视频常用中近景+特写切节奏
- 剪映操作链：粗剪（分割/删除）→ 配乐 → 字幕（**必配**，静音场景多；口播用智能字幕，纯音乐用识别歌词）→ 转场 → 滤镜 → 模板（片头片尾/关注引导）
- 导出：1080p MP4 足够（抖音上限1080p，4K无意义）

## 六、变现路径

| 路径 | 门槛/要点 |
|---|---|
| 星图接广告 | 官方平台，10万粉起 |
| 全民任务/全民星视频 | 低门槛官方任务，新人可做 |
| 电商带货 | 巨量百应挂车，适合有产品 |
| 知识变现 | 留资H5、小风车（需企业号认证+报白） |
| 代运营服务 | 代拍/代播按条或时长计费；代投流收服务费不对结果保证；整体代运营需对流量负责 |
| 卖账号 | 已过时，价格低不推荐 |

## 七、运营工具

- 热榜聚合：今日热榜（tophub）等——微博/知乎/B站/抖音各平台热点不同需区分，B站热点偏社区内容，抖音偏大众
- 营销日历：按节点提前蹭热点
- 文案提取工具：一键提取他人视频文案做对标分析
- 数据网站：达多多（每日免费额度）、蝉妈妈（付费）查达人数据
