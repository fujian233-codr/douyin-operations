# douyin-operations

抖音（Douyin）运营 Agent Skill —— 覆盖「定位 → 选题 → 脚本 → 发布自查 → 数据复盘 → 投流 → 直播 → 变现」全链路运营方法论，供 AI 编程助手（Claude Code / Codex / 其他支持 SKILL.md 规范的 Agent）作为领域知识加载。

## 何时触发

- 起新号、做账号定位、规划变现路径
- 策划选题、撰写口播脚本 / vlog 脚本 / 情景剧剧本
- 视频发布后流量异常（限流 / 播放低）排查
- 数据复盘、对标同行、决定下一条内容方向
- DOU+ 投放决策、免费推广引流
- 直播带货筹备与复盘

关键词：流量池、完播率、限流、涨粉慢、蹭热点、对标账号、脚本公式等。

## 核心机制速览

| 机制 | 要点 |
|---|---|
| 审核两层 | 机审（敏感词 / 广告法词 / 搬运去重）→ 疑似违规才人审 |
| 流量池阶梯 | 初始 200–300 播放 → 达标进 ~3000 池 → 逐级放大 |
| 标签系统 | 平台靠分发人群的行为数据识别赛道，而非标题文案 |
| 指标权重 | 关注 > 点赞评论 > 完播；实操顺序反过来：先完播 → 互动 → 关注 |
| 数据基准 | 5 秒完播率 ≥50% 达标；<500 播放的数据无分析价值 |

## 安装使用

将本仓库克隆到你的 Agent 技能目录（以 Codex 为例）：

```bash
git clone https://github.com/fujian233-codr/douyin-operations.git \
  ~/.codex/skills/douyin-operations
```

其他 Agent 请放到对应的 skills 目录。安装后无需任何配置，对话中出现运营相关诉求时 Agent 会自动加载。

## 说明

- 方法论基于国内短视频平台通用运营实践整理，部分数据基准（如 DOU+ 价格、开通流程）随平台政策变动，以官方现行规则为准。
- 仅收录合规运营方法；刷量、无人直播等平台明令禁止的操作不在收录范围。
- 本 skill 用于辅助内容创作决策，不构成任何投放效果的保证。
